プライバシーポリシー

最終更新日: 2026年10月11日

SwitchBot Controller（以下「本拡張機能」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めます。

収集する情報

本拡張機能が収集・保存する情報は以下のみです。

  • SwitchBot API トークン — ユーザーが設定画面に入力したもの
  • SwitchBot クライアントシークレット — ユーザーが設定画面に入力したもの
  • デバイスキャッシュ — デバイスの名称・種類・IDなどを含む一覧。読み込み時に最大30秒間再利用します
  • 機器の並び順 — 並び替えた機器のIDを表示順に保存します

情報の利用目的

認証情報は、SwitchBot API へのリクエスト認証に使用します。機器の並び順は、ポップアップの表示順を復元するために使用し、外部には送信しません。デバイスの一覧・状態情報は、対応デバイスの表示、検索、状態確認とコマンド送信に使用します。

情報の保存場所

入力されたAPIトークン・シークレットとデバイス一覧のキャッシュ、機器の並び順は、ブラウザのローカルストレージ（chrome.storage.local または browser.storage.local）に保存します。開発者のサーバーには送信しません。キャッシュの再利用期間は30秒ですが、期限切れのキャッシュも更新・削除されるまで保存される場合があります。ローカル保存に、本拡張機能独自の暗号化は行っていません。

第三者への情報提供

本拡張機能は、ユーザーの情報を販売しません。デバイスの取得・操作に必要な情報を、SwitchBot の公式 API（api.switch-bot.com）に送信します。広告・アクセス解析や、単一目的と無関係な利用は行いません。

外部サービスとの通信

本拡張機能が通信する外部サービスは以下のみです。

  • SwitchBot API（https://api.switch-bot.com）— デバイスの操作・状態取得のため、HTTPSで通信します。APIトークン、HMAC-SHA256認証署名、タイムスタンプ、nonce、操作対象のデバイスIDとコマンドなどを送信し、デバイス一覧・状態情報を受信します。シークレットそのものは送信せず、ブラウザ内で署名生成に使用します

データの削除

設定画面の「認証情報を削除」ボタンを押すことで、本拡張機能が保存したAPIトークン・シークレット、デバイス一覧のキャッシュと保存した機器の並び順を削除できます。SwitchBot側のアカウントやデバイス登録情報は削除されません。拡張機能をアンインストールすることでも、すべてのデータが削除されます。
